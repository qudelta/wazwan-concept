You’ll learn · 2 of 5Hands-on

How a model is trained and tested.

1What train-test splitting really does

Hold part of the data back, so the model is judged on examples it has never seen.

Training data · 80%Test data · 20%
2What model training means

The model adjusts itself, step by step, to reduce its error on the training data.

3Why we use k-fold cross-validation

Rotate which part is held out, so every data point gets tested once. The average score is far more trustworthy than a single split.
