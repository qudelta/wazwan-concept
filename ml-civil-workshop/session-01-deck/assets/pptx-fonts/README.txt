Fonts for the editable Session 01 PowerPoint
============================================

The fonts are embedded in Session-01_..._EDITABLE.pptx, so the deck should look right without installing anything.
Install these anyway on the presenting Mac (and on any computer used to edit the deck); it is the safest setup.

Mac: select all the .ttf files, double-click, then click "Install" in Font Book. Quit and reopen PowerPoint.
Windows: select all the .ttf files, right-click, "Install for all users".

Archivo (Omnibus-Type) and JetBrains Mono (JetBrains) are free fonts under the SIL Open Font License (see the OFL files).
