Civil engineers already build models

ML is another engineering modelling tool.

Theory & mechanicsfirst principles
Empirical correlationse.g. Abrams’ law (1918)
Numerical modelsFEM · FDM
Laboratory / field datacube, cylinder & field tests
Data-driven modelslearned from examples
Machine learning learns relationships from examples in data.

We already build models. We use equations, correlations, numerical models, experiments and design standards.

Machine learning doesn’t suddenly replace engineering thinking. It gives us another way to represent relationships when we have sufficient data.

Machine learning is another modelling approach
The important difference is that instead of prescribing the relationship ourselves, we allow an algorithm to learn a relationship from examples in data.

Unsupervised learning

Takes data without labels and tries to automatically group them into clusters.

No strength labels. Three binder families emerge.

k-means on 1,030 mixes, using only how the binder is made up.
Data only comes from Input (X) but not output label (Y). Algorithm has to find structure in the data.
  • ClusteringGroup similar datapoints together.
  • Anomaly detectionFinds unusual data points, e.g. a faulty sensor reading.
  • Dimensionality reductionCompress data into fewer variables while keeping its structure.

What is it with the name? · Why is it called Python?

Named after a comedy show, not a snake.

The name Python doesn’t come from the snake, even though the logo and community themes often use snake imagery.

Python was named after the British comedy group “Monty Python’s Flying Circus”, a favourite of Python’s creator, Guido van Rossum.

He wanted a name that was short, unique, and a little mysterious or fun, and “Python” felt just right.
