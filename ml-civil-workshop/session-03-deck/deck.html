Linear regression: our first model

Why start with linear regression?

The prediction is a weighted sum of the inputs
ŷ = β0 + β1x1 + β2x2 + … + β8x8
xjthe input variables
βjlearned coefficients (weights)
β0the intercept
ŷpredicted strength

Simple

One equation you can write on a board.

Fast

Fits 804 mixes in milliseconds.

Interpretable

Every input has a visible weight.

A benchmark

The reference for trees and neural networks later.

Simple does not mean useless.

Some maths behind ML models · 1 of 5

Linear regression: the base model of statistical ML

The model · one input
fw,b(x(i)) = wx(i) + b

Parameters: slope w and intercept b.

The cost · squared-error cost function
J(w,b) = 12mΣi=1m ( fw,b(x(i)) − y(i) )2

Square every error, average over the m examples.

The goal
minimise J(w, b) over w, b

With 8 inputs it is the same idea: one w per input.

26 real 28-day mixes, one input: cement

Some maths behind ML models · 3 of 5

Gradient descent: follow the slope downhill

Repeat until convergence:
w = w − α ∂∂wJ(w,b)
b = b − α ∂∂bJ(w,b)
α learning rate: step sizederivative: slope of J
Why it works

A negative slope makes w grow; a positive slope makes it shrink. Steps get smaller as the slope flattens near the minimum.

Update w and b together, using the slope at the current point.

J(w) with b at its best value

Feature scaling: make the bowl round

Once the features are selected, they may not be on the same scale: cement varies by about 104 kg/m³, superplasticizer by about 6.

Problematic

Features with larger scales can dominate comparisons, and gradient descent crawls along a long, narrow valley.

Therefore, standardise

Mean 0, standard deviation 1 for every feature. It stabilises the optimisation used in ML algorithms.

Prediction is not enough

A model can make predictions. How good are they?

We need a scorecard. Today: three regression metrics.
MAE

Mean Absolute Error

unit: MPa · lower is better

On average, how large is the error?

RMSE

Root Mean Squared Error

unit: MPa · lower is better

How large is the error, with big misses counting more?

R²

Coefficient of Determination

no unit · higher is better, max 1

How much better than predicting the mean?

Different metrics answer slightly different questions.

Metric 1 · on our 201 test mixes

MAE: Mean Absolute Error

Question · on average, how large is our prediction error?
MAE = 1mΣi=1m | yi − ŷi |
actual target value  ·  predicted target
Why engineers like MAE
  • Same units as the target: MPa
  • Easy to interpret
  • Every error contributes in proportion to its size

Metric 2 · large errors are penalised more strongly

RMSE: Root Mean Squared Error

Squares the errors before averaging
RMSE = √ 1mΣi=1m ( yi − ŷi )2
Why squaring matters · errors of two models on 4 mixes
A 3333 → MAE 3.0 · RMSE 3.0
B 00012 → MAE 3.0 · RMSE 6.0
  • MAE → average error size
  • RMSE → average error with a greater penalty for large misses
Linear regression · test set
11.2MPa

RMSE ≥ MAE always. Here the gap (11.2 vs 8.9) says some mixes are missed by a lot.

Mean baseline: 17.3 MPa. Lower is better.

Metric 3 · how much variation does the model explain?

R²: compared with the mean baseline

Model error relative to baseline error
R² = 1 − Σ ( yi − ŷi )2Σ ( yi − ȳ )2
ȳ arithmetic mean of y = the baseline
R² = 1perfect predictions
R² = 0no better than the mean
R² < 0worse than the mean, possible on unseen data
Important · R² is NOT accuracy

R² = 0.58 does not mean “58% of predictions are correct”. It means the squared error is 58% smaller than the mean baseline’s.

Linear regression · test set
0.58

The model explains well over half the variation in strength that the mean leaves unexplained.

Mean baseline: 0.00, by construction.

Residual = actual − predicted · where and why is the model wrong?

Residuals help us diagnose the model

Against the prediction

Ideally: centred on zero, no pattern.

Against age: a clear curve

Blue: median residual at each test age.
Warning signs
Curvature→ the linear model misses nonlinear behaviour. Here: −12.7 MPa at 3 days, +11.6 at 56, −9.6 at a year.
Increasing spread→ the error changes with the target or input range
Large isolated residuals→ unusual observations or difficult cases
Don’t just ask “how good is the score?” Ask “where and why is the model wrong?”

The most important rule from today

Keep the test set untouched during development

The test set is for the final evaluation.

Use it once, at the end.

Do not use test performance to decide which
  • Model
  • Features
  • Hyperparameters
  • Pre-processing approach
is better. Every peek turns the test set into training data.
